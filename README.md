# 🛒 ShopSmart

**ShopSmart** is a smart shopping list management application designed to make shopping more organized, budget-friendly, and convenient. It allows users to create personalized shopping lists, track purchases, monitor spending, and get intelligent suggestions for their shopping needs.

## ✨ Features

* 📝 **Personalized Shopping Lists** — Create, edit, and manage your own shopping lists and add items according to your needs.
* 🛒 **Item Management** — Add, edit, and manage items within your shopping lists.
* ✅ **Purchase Tracking** — Mark items as purchased and keep track of what has already been bought.
* 💰 **Price Tracking & Budget Management** — Track item prices, manage your shopping budget, and monitor your spending.
* 📊 **Shopping Insights** — Get useful insights into your shopping habits and spending.
* 💡 **Smart Suggestions** — Receive intelligent suggestions to make shopping more efficient.
* 🤖 **AI Meal Planner** — Enter any meal name and get a list of its required ingredients. Ingredients can be directly added to your shopping list.

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript, HTML, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / MongoDB Atlas
* **Authentication:** JWT
* **APIs:** REST API & Meal/Recipe API
* **Tools:** Git, GitHub, VS Code, Postman

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd ShopSmart
```

### 2. Install dependencies

For the backend:

```bash
cd backend
npm install
```

For the frontend:

```bash
cd frontend
npm install
```

### 3. Configure environment variables

Create a `.env` file in the backend directory:

```env
PORT=5001
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```

### 4. Run the application

Start the backend:

```bash
npm start
```

Start the frontend in another terminal:

```bash
npm run dev
```

## 🎯 Project Goal

ShopSmart aims to provide an all-in-one solution for **organizing shopping lists, tracking purchases, managing budgets, understanding shopping habits, and simplifying meal planning**.
